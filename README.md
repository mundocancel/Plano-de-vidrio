# 📐 Plano de Vidrio Templado — MundoCancel

Herramienta offline para generar planos técnicos acotados de pedidos de vidrio templado, con plantillas preconfiguradas para los tipos más comunes de cancelería y barandales.

## 🎯 Qué hace

- Genera planos SVG acotados estilo **blueprint/CAD**.
- Incluye plantillas con estándares reales de herrajería:
  - Puerta de baño (bisagras + manillón)
  - Puerta corrediza (kit riel)
  - Fijo de cancel (conectores)
  - Fijo barandal (sin mecanizados)
- Perforaciones y resaques con coordenadas exactas.
- Resaques con esquinas redondeadas (radio parametrizable).
- Exportación a **DXF** para templadoras y CNC.
- Impresión/PDF con membrete profesional B&N.

## 🚀 Cómo usarlo

### Opción 1: Abrir directamente
Doble clic sobre `index.html` → se abre en tu navegador. Funciona 100% offline.

### Opción 2: GitHub Pages (recomendado para el taller)
1. Ve a **Settings → Pages** del repo.
2. Source: `Deploy from a branch` → `main` → `/ (root)`.
3. URL pública: `https://mundocancel.github.io/Plano-de-vidrio/`
4. Accede desde cualquier PC o celular del taller.
